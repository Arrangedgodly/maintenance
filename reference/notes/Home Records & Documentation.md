# Home Records & Documentation

> The lowest-effort, highest-leverage system in the workspace: six categories of information, captured once, that pay off when something breaks, when you sell, and when you're standing in the paint aisle. No tools, no skills — just writing things down where you can find them.

## Summary
Six things to track: **(1) Equipment register** — model + serial + install date for every appliance and system. Pays off at 11pm when something breaks and the manufacturer needs a model number you can't see because the unit is behind a panel. **(2) Maintenance log** — dated record of every task, so "when did I last flush the water heater?" has an answer. **(3) Finishes register** — paint brand + name + sheen, tile brand + color, flooring species + width, per room. Pays off when you touch up a wall or replace a broken tile. Tip: write paint info on tape on the back of each room's switch plate. **(4) Shutoff map** — water main (ball or gate, photo, tagged), gas valve location, main electrical breaker, fixture valves. **Print it** — a flood or storm kills your phone. **(5) Trusted pros list** — name, trade, license number, what they did, "would hire again." **(6) Document file** — warranties, permits, receipts, inspection reports, closing docs. Permits + inspections prove legal work at resale. **Format:** hybrid — this workspace's [[NOTES|equipment register]] + [[ACTION-ITEMS|maintenance log]] are the digital half; a physical binder holds the paper originals (warranties, permits, receipts).

## The six things to track

### 1. Equipment register (model + serial + install date)
The single most useful record when something breaks. The manufacturer needs the model + serial — which is on a label you can't see because the unit is in a closet or behind a panel. Capture once, never pull the unit out again just to read it.

| Appliance/System | Record | Where the label is |
|---|---|---|
| HVAC (AC condenser) | Carrier 24SPA630W003, serial BC54925100 | Side panel of outdoor unit |
| Furnace | Carrier 58TP0B090V17-116 | Rating plate in burner compartment |
| Water heater | Bradford White RG250T6N | Sticker on side of tank |
| Dryer | Maytag MED5630HC | Inside door opening or rear |
| Washer | Maytag MHW5630HC (confirm) | Inside door opening or rear |
| Refrigerator | [capture] | Inside on side/ceiling wall |
| Dishwasher | [capture] | Side of door or frame |

### 2. Maintenance log
Dated log of every maintenance task + repair. The value isn't what you did — it's **when you did it last**, so you know when it's due.

| Date | System | Task | Notes |
|---|---|---|---|
| YYYY-MM-DD | HVAC | Filter change | Size, MERV, dirt level |
| YYYY-MM-DD | Plumbing | Main valve exercised | Ball/gate, works freely? |
| YYYY-MM-DD | Dryer | Vent clean | Material, airflow result |

Format doesn't matter (notebook, spreadsheet, [[ACTION-ITEMS]]). The habit does: log it when you do it.

### 3. Finishes register (paint, tile, flooring)
Capture once when the info is available (move-in, renovation, painting). You will NOT remember "SW Pure White, eggshell" in two years.

| Room | Surface | Finish |
|---|---|---|
| Living room | Walls | Brand + name + sheen |
| Living room | Trim | Brand + name + sheen |
| Kitchen | Backsplash | Brand + color + size |
| Bathroom | Floor | Brand + color + size + grout color |
| Throughout | Flooring | Brand + species/color + plank width |

> **Tip:** write paint name + brand + sheen on tape on the back of the switch plate in each room. The info lives with the room forever.

### 4. Shutoff map
In an emergency, anyone in the house must be able to stop water/gas/power in under a minute.
- **Main water shut-off:** location, type (ball/gate), photo, tagged
- **Gas shut-off:** location of main gas valve. **If you smell gas, leave + call utility — don't DIY.**
- **Main electrical breaker:** panel location, which is the main (top, double-pole), photo of labeled schedule
- **Fixture valves:** under sinks, behind toilets, at washer — note which work and which are seized

> **Print the map. Tape it inside a cabinet near the panel or on the fridge.** Digital doesn't help in a flood.

### 5. Trusted pros list
For each pro vetted + would-hire-again:
- Name + trade
- Phone + email
- License number (verified)
- What they did + when + how it went
- Would you hire them again? (The gate question.)

### 6. Document file

| Document | Why | How long |
|---|---|---|
| Appliance warranties + manuals | Warranty claims; resale proof | Until warranty expires + 1 yr |
| Permits + inspection reports | Proof work was legal; required at resale | **Forever — stays with the house** |
| Contractor receipts + invoices | Tax basis for improvements; workmanship warranty | Until sale + tax retention period |
| Home inspection report (purchase) | Baseline of condition | Forever |
| Closing documents (deed, title, survey) | Legal proof of ownership + boundaries | Forever |

## Format: hybrid (recommended)

| | Digital | Physical binder | Hybrid |
|---|---|---|---|
| Best for | Equipment, log, finishes | Warranties, receipts, permits (originals) | Both |
| Strength | Searchable, backupable, updatable | Works in outage; survives tech changes | Each covers the other's weakness |
| Weakness | Dead device in emergency | Not searchable; single copy | Slight redundancy — but that's the point |
