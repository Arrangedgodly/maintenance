# Ceiling Fan & Light Fixture Replacement

> The capstone of the electrical arc: adds weight and dynamic load to everything in [[Electrical Safety Fundamentals|safety]] and [[Light Switch Replacement|switches]]. Hinges on one question — is the box fan-rated?

## Summary
The gate question for any fan install: is the existing ceiling box a [[GLOSSARY#Fan-rated box (ceiling)|fan-rated box]]? Standard light boxes hold a static 50 lb fixture but are explicitly **not** rated for a spinning, torquing, vibrating fan — that's how fans fall. The [[GLOSSARY#NEC 35-lb fan rule|NEC 35-lb rule]] lets a listed fan box support a ≤35 lb paddle fan; anything heavier needs independent support to structure. If the box isn't fan-rated, install an [[GLOSSARY#Expansion brace (retrofit fan brace)|expansion brace]] from below (no attic access) and mount the fan-rated box that comes with the kit.

Control wiring is a [[GLOSSARY#14/3 cable (NM-B)|14/3]] vs 14/2 decision: a single switched hot (14/2) runs fan+light together (split at the [[GLOSSARY#Canopy (ceiling fan)|canopy]] via pull chains or a [[GLOSSARY#Remote receiver (ceiling fan)|remote receiver]]), while a 14/3 run carries independent switched hots for fan (black) and light (blue/red) to dual wall switches. Fishing 14/3 through finished walls is usually the moment a remote receiver wins. Blade height wants 7–9 ft off the floor; sloped ceilings need a minimum 12" [[GLOSSARY#Downrod|downrod]] plus a sloped-canopy adapter.

A properly installed fan does not wobble — wobble dynamically loads the box every oscillation and must be fixed (balancing kit, loose blade arms, loose brace), not ignored. A sub-50 lb light-fixture swap is a standard color-mapping job; just confirm the box rating on heavy chandeliers. Track installs in [[ACTION-ITEMS]].

## The gate: is the box fan-rated?
**Before buying a fan, before the ladder:** is the existing ceiling box rated for fan support?

| Box type | Static fixture | Fan |
|---|---|---|
| Standard light box (not fan-rated) | up to 50 lb | ⛔ **None — never mount a fan** |
| [[GLOSSARY#Fan-rated box (ceiling)|Fan-rated box]] (with brace) | up to 90–150 lb | up to 70 lb (brace/joist dependent) |

**How to tell:**
- Stamping: "For Fan Support" + weight rating (may need to pull light to see)
- Mounting: braced between joists or securely to one joist — not just side-nailed and wiggling
- **When in doubt, assume not.** Most existing light boxes aren't fan-rated.

> [[GLOSSARY#NEC 35-lb fan rule|NEC 35-lb rule]]: outlet boxes can support paddle fans ≤ 35 lb <em>only if listed for fan support</em>. >35 lb needs independent support to structure regardless of box rating.

## If not fan-rated: install a retrofit brace
[[GLOSSARY#Expansion brace (retrofit fan brace)|Expansion brace]] = telescoping metal bar wedged between two joists, installed from below (no attic access).
1. Breaker off, verify dead. Remove light fixture.
2. Remove old box (nailed/screwed to joist). Disconnect cable carefully (re-feed into new box). Enlarge hole if needed.
3. Insert brace through hole, rotate to span joists, expand until spikes bite, tighten per kit.
4. Mount fan-rated box (comes with kit) to brace. Feed cable via connector.
5. Patch ceiling if hole now exceeds canopy coverage.

> ⚠️ Heavier fans (>35 lb) may need independent hanger rod to joist — read manufacturer instructions. Don't exceed box/brace listed rating.

## Wiring: which control configuration?

| Config | Cable | Control |
|---|---|---|
| **A. Single switched hot** | 14/2 (black, white, ground) | Pull-chain or remote at fan |
| **B. Two switched hots** | [[GLOSSARY#14/3 cable (NM-B)|14/3]] (black, <em>red</em>, white, ground) | Dual wall switch (fan + light independent) |

**A — single hot:** fan + light share one switched hot. Control separately at fan via pull chains OR [[GLOSSARY#Remote receiver (ceiling fan)|remote receiver]] in canopy (splits single hot → independent fan + light; no wall wiring change; pragmatic when fishing 14/3 isn't viable).

**B — 14/3:** black → fan motor hot; red → light kit hot; white → shared neutral; bare → ground. Two wall switches control independently.

> Converting single-switch to dual-switch = pull new 14/3 between switch + ceiling (fishing walls) — often the moment a remote receiver becomes the better choice.

## Wire colors at the fan
- **Black** = fan motor
- **Blue** = light kit (cap if no light)
- **White** = neutral
- **Green/bare** = ground

Single switched hot + want wall switch to control both → wire fan black AND light blue to ceiling's switched hot.

## Install sequence
1. Breaker off, verify dead at ceiling box (every wire).
2. Assemble fan on floor per manual (downrod, blades — or leave blades off until hung per manual).
3. Wire at ceiling box (colors above). Use the mounting bracket's hang-the-motor feature while connecting — safer than balancing.
4. Tuck remote receiver above motor in canopy space (if used).
5. Slide [[GLOSSARY#Canopy (ceiling fan)|canopy]] up, secure. Install blades if left off.
6. Light kit last (if separate).
7. Breaker on. Test all speeds + light + no wobble + no odd noise.

## Downrod / blade height
Blades ideal: **7–9 ft above floor.** Rule of thumb: **ceiling height − 8 ft ≈ downrod length.**

| Ceiling | Downrod |
|---|---|
| 8 ft | None (hugger) |
| 9 ft | 3–6" or none |
| 10 ft | 12" |
| 12 ft | 24–36" |
| 14+ ft | 48–60"+ |

Sloped/vaulted: minimum 12" downrod + sloped-ceiling canopy adapter. Longer for steeper pitches.

## Wobble — fix immediately
Properly installed fan doesn't wobble. If it does:
- **Blade balance** → balancing kit (clip + weights) per manual
- **Loose/bent blade** → check blade-arm screws; look for warp
- **Loose box** → power off, bracket/box shouldn't move; if it does, brace isn't secure
- **Downrod too short on slope** → fan rubs at speed

> ⚠️ Wobble dynamically loads the box — every oscillation stresses mounting → eventually loosens. Fix cause, don't ignore.

## Light-fixture-only swap (under 50 lb)
Box weight rating usually fine. Wiring = standard color mapping (black-black, white-white, ground-ground). Only check: if fixture is heavy (large chandelier), confirm box rating.

## DIY / Pro boundary
| DIY | Call electrician |
|---|---|
| Fan swap where fan-rated box exists | Fishing new 14/3 through finished walls |
| Retrofit brace + fan-rated box install (comfortable) | Service-panel work |
| Light fixture swap (<50 lb) | Very heavy fixtures / chandeliers needing structural support |
| Remote receiver install | Any work you can't diagnose |
