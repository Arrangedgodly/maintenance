# Faucet Repair

> Second-most-common plumbing repair after [[Toilet Repair|toilets]] — almost every failure is one cheap wear part.

## Summary
Diagnosis by symptom: **low flow / spraying at one faucet** = clogged [[GLOSSARY#Aerator|aerator]] (unscrew, vinegar soak — the #1 and easiest fix); **drip from the spout** = worn [[GLOSSARY#Cartridge (faucet)|cartridge]] on single/two-handle faucets, or a washer on older [[GLOSSARY#Compression valve (faucet)|compression]] two-handle faucets; **leak at the base of the spout** (not the tip) = worn spout [[GLOSSARY#O-rings (faucet)|O-rings]]. The single most useful diagnostic is removing the aerator entirely and running the faucet — strong flow means the aerator was it, weak flow means the problem is upstream. Cartridges are brand-and-model-specific (no generic part): Moen's 1225/1222 ship free under warranty; Delta and others vary. Higher-end modern faucets use long-lived [[GLOSSARY#Ceramic disk cartridge|ceramic disk]] cartridges. Shut off both [[GLOSSARY#Shut-off valve (angle stop / stop valve)|supply valves]] before any internal work; never pry against the brass faucet body (score risk). If hot/cold come out reversed after a cartridge swap, the cartridge is 180° off — rotate, don't chase a supply-line problem. Whole-house low pressure at every fixture is not a faucet problem (pressure regulator / plumber).

## Diagnosis flow (read first)

| Symptom | Likely cause | Fix |
|---|---|---|
| Low flow / spraying at ONE faucet (others fine) | Clogged [[GLOSSARY#Aerator|aerator]] | Unscrew, vinegar soak, reinstall (~10 min, $0) |
| Drip from spout (handle off) | Worn [[GLOSSARY#Cartridge (faucet)|cartridge]] (single/two-handle) or washer (compression) | Replace cartridge/washer (~$15–35, 30 min) |
| Leak at BASE of spout (onto counter) | Worn spout [[GLOSSARY#O-rings (faucet)|O-rings]] | Pull spout, replace O-rings (~$5, 20 min) |
| Low flow at EVERY fixture | Not faucet — whole-house pressure | Pressure regulator / plumber (out of scope) |
| Handle hard to turn / won't shut off | Cartridge seized / mineral-fouled | Replace cartridge (don't force handle — snap risk) |

> **Single most useful diagnostic:** unscrew aerator entirely, run faucet. Strong flow = aerator was it. Still weak = problem is upstream (valve/supply/cartridge).

## Repair 1 — Aerator clean/replace (low flow at one faucet)
[[GLOSSARY#Aerator|Aerator]] = screw-on screen at faucet tip. Mixes air into water; clogs with calcium → weak/spraying stream. #1 faucet "repair," easiest DIY plumbing.
1. Unscrew by hand. Stuck → rubber band/cloth for grip, pliers **through cloth** (don't scratch finish).
2. Note parts order (washer, screen, mixer, housing) — lay out for reassembly.
3. Soak in white vinegar 20–30 min (overnight or CLR for heavy calcium).
4. Scrub with old toothbrush. Backflush screen (inside out under running water).
5. Screen torn/permanently crusted → replace aerator entirely (~$5, universal — verify male/female + standard/fine thread).
6. Reassemble same order, hand-tight. Don't overtighten.

> **Keyed aerator:** modern pull-out faucets may use specialized aerator with 2 notches → needs "aerator key" (~$5).

## Repair 2 — Cartridge (drip from spout)
Internal valve mechanism. Brand-and-model-specific — **no generic cartridge.**

### Identify first
- **Brand:** logo on handle, spout, or base (Moen, Delta, Kohler, Pfister, American Standard)
- **Model:** original paperwork, stamp on spout underside/base, or mfr website ID tool (Moen/Delta both excellent)
- **Handle type:** single-handle / two-handle / lever

### Moen — the easy case
1225 (single-handle older) / 1222 (PosiTemp shower) = most-installed cartridges in US plumbing history. ~$15. Moen customer service ships free under warranty. Identify model → call Moen.

| Faucet type | Brand | Part |
|---|---|---|
| Single-handle | Moen/Delta | Cartridge (Moen 1225/1222; Delta RP-series) |
| Two-handle modern | Most | Cartridge (1 per handle — hot + cold separate) |
| Two-handle older (multi-turn) | Various | [[GLOSSARY#Compression valve (faucet)|Compression]] washer + seat |
| Higher-end modern | Various | [[GLOSSARY#Ceramic disk cartridge|Ceramic disk]] cartridge |

### Procedure (single-handle cartridge)
1. Shut off both supply valves (hot + cold). Open faucet, relieve pressure.
2. Remove handle: pry decorative cap, loosen set screw (usually Allen), lift handle off.
3. Remove escutcheon/dome cap (hand or strap wrench, cloth-wrapped).
4. Remove retaining clip or nut (brass clip pulls up, or plastic nut unscrews). Note orientation.
5. Pull cartridge straight up. Seized → cartridge puller (~$10, brand-specific). **Don't pry against faucet body — scores brass.**
6. Note cartridge orientation (hot/cold inlet direction) before removing.
7. Install new cartridge same orientation, fully seated.
8. Reinstall clip/nut, escutcheon, handle, set screw, cap.
9. Restore water slowly. Test — smooth handle, no drip, hot/cold correct sides. (Reversed = cartridge 180° off → rotate.)

> **Hot/cold reversed after repair?** Cartridge installed 180° rotated. Pull, rotate half-turn, reinstall. Not a supply-line problem.

### Compression washer faucets (older two-handle, multi-turn handles)
Wear part = rubber washer at bottom of valve stem (~$2).
1. Shut off, relieve pressure, remove handle.
2. Unscrew valve stem (valve socket wrench or pliers on stem nut).
3. Unscrew old washer at stem bottom, screw on new (same size).
4. **Inspect valve seat** (brass surface washer presses) — grooved/rough chews new washer. Valve seat wrench (~$5) replaces seat, or seat dresser re-surfaces.
5. Reassemble reverse.

## Repair 3 — Spout O-rings (leak at base)
Water at spout base (not tip) = worn spout [[GLOSSARY#O-rings (faucet)|O-rings]]. Different from cartridge — pull spout, don't open valve.
1. Shut off supply. Loosen spout collar set screw.
2. Pull spout straight up off body. (On pull-out kitchen faucet: swivel spout base, not pull-out head.)
3. Inspect O-rings on body where spout sat — cracked/flat/crumbly.
4. Replace with identical (universal faucet O-ring kit ~$5). **Lubricate new rings with silicone plumbers grease** (not petroleum jelly — degrades rubber) before sliding spout on.
5. Reinstall spout, tighten set screw, restore water, test.

## Toolkit
- Adjustable pliers (Channellock) — $15
- Allen wrench set — $10
- Strap wrench (escutcheons — won't scratch) — $10
- Cartridge puller (brand-specific, if needed) — $10
- Valve seat wrench (compression only) — $5
- O-ring pick / small flathead — $5
- Silicone plumbers grease — $5
- White vinegar — $3

## DIY / Pro boundary
| DIY | Call plumber |
|---|---|
| Aerator clean/replace | Whole-house low pressure (PRV/main) |
| Cartridge replacement (brand identified) | Seized cartridge you can't remove safely |
| Compression washer + seat | Wall-mounted/shower faucets (behind-wall access) |
| Spout O-ring replacement | Corroded supply line won't disconnect |
| Handle replacement | Can't identify faucet brand/model |
